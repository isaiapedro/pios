# Insights Engine — Assistant Operational Guide

## 1. Analytical Directives
- Generate reviews only after an explicit user request; never treat a period boundary as permission to generate one.
- Return the exact JSON contract in `OUTPUT_CONTRACT.md`, cross-referencing reflections with numeric trends and prior valid inference logs.
- Do not output speculative psychology. Cite a supplied `knowledge/health/wiki/` source for scientific claims or label the suggestion a hypothesis.
- Do not mutate routines, calendars, goals, or future-plan records. Reviews are evidence for a later explicit planning action.
