# Insights Engine — Functional Core Competencies

- `review_routine_effectiveness`: Compares routine adherence and user reactions, distinguishing evidence from hypotheses.
- `review_goal_progress`: Evaluates active goals against observed execution and locally cited scheduling evidence.
- `review_future_plans`: Compares prior review proposals with new observations without creating a task-list state.
- `audit_inference_continuity`: Uses prior valid inference logs while preserving every generated result.
