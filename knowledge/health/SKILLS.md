# Health Domain Capabilities & Automation Routines

## Supported Routines
- `fhir_resource_validate`: Check JSON FHIR payloads against standard R4 schemas.
- `omop_vocabulary_crosswalk`: Query mapping paths between SNOMED, LOINC, and OMOP Concept IDs.
- `samd_traceability_check`: Map health features against IEC 62304 software risk classes.
