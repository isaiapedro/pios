# Health Domain Context

This directory stores knowledge related to health data standards, clinical informatics, and health IT architecture.

## Primary Knowledge Assets
- `raw/HL7 FHIR R4`: Fast Healthcare Interoperability Resources (R4 specification).
- `raw/OMOP CDM v5.4`: Observational Medical Outcomes Partnership Common Data Model.
- `synthesized/`: Cross-walks, mapping strategies, and integration guides.

## Execution Directives
- Reference `ONTOLOGY.md` for entity mappings between FHIR resources and OMOP tables.
- Validate REST resources against FHIR R4 structure definitions before proposing API payloads.
