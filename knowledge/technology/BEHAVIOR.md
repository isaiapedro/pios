# Technology Domain Behavioral Guidelines

## Engineering & Architecture Rules
1. **Design Pattern Standards**: Software patterns, code snippets, and infrastructure configurations must follow modern production-grade practices.
2. **Explicit Dependency Declarations**: All system design docs must state technology stack requirements, runtime dependencies, and API version constraints.
3. **Security First**: Architectural patterns must integrate authentication, authorization, data encryption at rest/in transit, and secret management by default.

## Synthesis & Processing Rules
- Place raw protocol specs and third-party developer docs under `raw/`.
- Store software design templates, architectural decision records (ADRs), and stack implementation guides under `synthesized/`.
