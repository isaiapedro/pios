# Technology Domain Context

This directory stores engineering standards, architectural decisions, dev guidelines, and technical infrastructure patterns.

## Primary Knowledge Assets
- `raw/`: Upstream technical specifications, RFCs, and API docs.
- `synthesized/`: System architecture patterns, stack guides, API design rules, and infrastructure blueprints.

## Execution Directives
- Follow clean architecture principles and modular software design when drafting technical guides.
- Ensure API design specifications align with FHIR data modeling conventions in `knowledge/health/` and IEC 62304 software life cycle rules in `knowledge/business/`.
