# Media Domain Context

This directory handles knowledge related to blog management, publication workflows, media pipelines, and content distribution.

## Primary Knowledge Assets
- `blog_manager/`: Editorial guidelines, publishing configurations, and blogging strategies.
- `raw/`: Unprocessed audio/video transcriptions, raw interview logs, and external content archives.
- `synthesized/`: Formatted articles, newsletter drafts, social media playbooks, and content reuse frameworks.

## Execution Directives
- Follow the voice guidelines in `blog_manager/CLAUDE.md` when drafting content.
- Ensure visual asset requirements reference style rules in `knowledge/arts/`.
