# Arts Domain Ontology & Concept Map

## Key Entities & Frameworks

### 1. Visual & UI Design
- **Design Systems**: Design tokens (color, typography, spacing, elevation, border-radius).
- **Typography & Layout**: Font pairings, modular scales, grid systems, and visual hierarchy.
- **Brand Aesthetics**: Color theory, moodboards, icon sets, and art direction.

### 2. Creative Writing & Audio/Visual Arts
- **Narrative Design**: Storytelling structures, creative prose techniques, and voice dynamics.
- **Audio/Visual Production**: Color grading palettes, sound design principles, and composition rules.

## Inter-Domain Relationships
- **Arts -> Media**: Provides visual templates, branding guidelines, and graphic assets for publishing (`knowledge/media/`).
- **Arts -> Technology**: Design tokens map directly to CSS variables, Tailwind themes, and UI components (`knowledge/technology/`).
