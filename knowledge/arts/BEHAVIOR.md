# Arts Domain Behavioral Guidelines

## Creative & Design Rules
1. **Design System Consistency**: Visual tokens (color palettes, typography scales, spacing rules) must follow declared design system standards.
2. **Creative Asset Organization**: Store raw artwork, vector source files, and moodboards in `raw/`. Store synthesized design systems and style guides in `synthesized/`.
3. **Accessibility**: All visual design specs and web layouts must adhere to WCAG accessibility guidelines (color contrast, text legibility).

## Synthesis & Processing Rules
- Maintain unified branding rules for all public-facing assets produced across `media/` and `personal/`.
- Cross-link UI design tokens to CSS/Tailwind configurations in `knowledge/technology/`.
