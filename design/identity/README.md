## Reuse rule

1. Start from the product dossier under `identity/<product>/`.
2. Prefer **canonical mobile tokens** when building React Native / Expo.
3. Treat editorial / Figma prototype tokens as **heritage or exploration**, not overrides, unless the new surface is deliberately editorial.
