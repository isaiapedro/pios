Real Petlove (Caramelo) icon glyphs, rendered by name and painted with `currentColor`.

```jsx
<Icon name="cart" size={24} />
<Icon name="heart" size={20} color="var(--c-heart)" />
```

21 glyphs available: arrow-right, cart, cat, check, chevron-down/left/right, close, close-circle, danger, dog, gift, heart, home, info, minus-circle, plus, search, star, success, warning. The full Petlove set (~271 glyphs, Material-style naming) lives in Figma — extract more with fig_materialize as needed.
