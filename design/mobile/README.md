# Mobile

Mobile-specific IA, chrome, and motion patterns. Figma Make prototypes for Chess Wrapped live under `chess app/`; the shipping pattern dossier is `chess-wrapped/`.

## Layout

| Path | Kind |
|------|------|
| `chess-wrapped/` | Extracted Expo implementation guide |
| `chess app/ui/` | Figma Make prototype (Playfair / neo-brutal filters) |
| `chess app/Enhance App Visuals (2)/` | Alternate Figma Make direction (Fraunces / softer accents) |
| `chess app/Enhance App Visuals.zip` | Archive |

## Reuse order for new mobile apps

1. Read `chess-wrapped/README.md` (shell, tabs, loaders, filters).
2. Pull tokens/components from `../ui/chess-wrapped/` and `../identity/chess-wrapped/`.
3. Open Figma prototypes only when exploring a different editorial direction.
