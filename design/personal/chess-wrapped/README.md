# Chess Wrapped

Personal chess analytics product. Its visual assets and editorial identity belong only to Chess Wrapped.

## Structure

- `shared/assets/` — app icons, splash marks, and licensed marketing piece artwork.
- `shared/identity/` — brand language and architecture notes.
- `shared/references/` — source map, provenance, and licensing context.
- `mobile/implementation/` — shipping Expo navigation and shell dossier.
- `mobile/ui-kit/` — primitive visual recipes and token snapshot.
- `mobile/prototypes/figma-make/` — retained Figma Make source and configuration.

The canonical runtime source remains `workspace/side_projects/chess/mobile/`.
