Icon-only circular action. Pairs with the Caramelo `Icon` set.

```jsx
<IconButton name="heart" type="danger" weight="ghost" ariaLabel="Favoritar" />
<IconButton name="cart" type="default" weight="primary" />
```

Types: `default`, `danger`, `neutral`. Weights: `primary` (filled), `secondary` (outlined), `ghost`. Sizes sm/md/lg = 40/48/56px. Always pass `ariaLabel`.
