# Petlove Shop — UI kit

An interactive, mobile-first recreation of the Petlove storefront, composed entirely from Caramelo design-system components.

## Run
Open `index.html`. It loads the compiled `_ds_bundle.js`, `data.js` (sample products) and `screens.jsx`.

## Flow
- **Home** — brand top bar (logo, search, address), category rail, Clube Petlove banner, 2-up product grid.
- **Product detail** — tap any product → image, brand, rating, price, quantity + add-to-bag.
- **Cart** — checkout stepper, editable line items (Counter / remove), order summary, finalize.
- **Bottom nav** switches sections; the cart badge tracks item count; a snackbar confirms adds.

## Components used
PetloveLogo, SearchBar, Chip, ProductCard, Price, Rating, Counter, Button, IconButton, Icon, Badge, Banner, Stepper, Divider, BottomNav, EmptyState.
